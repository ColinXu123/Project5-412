About this site

Broth & Noodle is a small student project about ramen, built for CSCE 412 and served from a private Amazon S3 bucket through CloudFront with HTTPS.

How the site is hosted

  • Amazon S3 stores the files and is not publicly readable.
  • CloudFront delivers the pages over HTTPS and is the only service allowed to read the bucket.
  • Route 53 points the domain at CloudFront.
  • AWS Certificate Manager provides the TLS certificate.
